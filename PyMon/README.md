# ⚡️PyMon

A basic Pokémon game developed in Python, featuring a main menu and several modules that organize the game's logic. 🎮

## Project structure

- `main.py` — Game entry point and main menu.
- `pokemon.py` — Pokémon management.
- `trainer.py` — Trainer management.
- `battle.py` — Battle system.
- `utils.py` — Helper functions.
